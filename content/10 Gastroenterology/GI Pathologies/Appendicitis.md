# Definition
- Acute inflammation of the vermiform appendix, a blind-ended tube attached to the cecum, typically caused by an obstruction
# Etiology
- Fecaliths in adults or lymphoid hyperplasia in children
# Epidemiology

# Clinical features
- Pain begins mid-epigastric and moves to McBurney’s point in the RLQ
# Investigations
- Diagnosis is made via history, exam, or CT scan
- Various physical exam tests can be used (see [Abdominal Exam](18%20Clinical%20Exams/Abdominal%20Exam.md))
	- McBurney's point, Rovsing's sign, psoas test, obturator test
# Prognosis

# Treatment 
- Surgical removal
